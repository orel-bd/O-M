# O&M — אישורי הגעה לפדיון הבן

אתר סטטי (HTML בלבד) שרץ על GitHub Pages. בלי שרת ובלי מסד נתונים — האישורים נשמרים בגיליון Google Sheets שלכם דרך Google Apps Script (חינם).

| קובץ | מה זה |
|---|---|
| `index.html` | ההזמנה + טופס אישור הגעה (את הקישור הזה שולחים לאורחים) |
| `guests.html` | רשימת כל המאשרים, סיכומים, חיפוש והורדה לאקסל (מוגן בסיסמה) |
| `config.js` | **פרטי האירוע** — שם התינוק, תאריך, מקום וכו׳ |
| `apps-script/Code.gs` | הקוד שמודבק בגוגל שיטס ושומר את האישורים |

## 1. פרטי האירוע
עורכים את `config.js`.

## 2. חיבור לגוגל שיטס (5 דקות)
1. פותחים גיליון חדש ב-[sheets.new](https://sheets.new).
2. **הרחבות ← Apps Script**. מוחקים את מה שיש ומדביקים את כל התוכן של `apps-script/Code.gs`.
3. משנים את `ADMIN_KEY` בשורה 6 לסיסמה משלכם. שומרים.
4. **פריסה ← פריסה חדשה ← סוג: אפליקציית אינטרנט**
   - הפעלה בתור: **אני**
   - למי יש גישה: **כל אחד**
5. מאשרים את ההרשאות ומעתיקים את כתובת ה-Web App (מסתיימת ב-`/exec`).
6. מדביקים אותה ב-`config.js` בשדה `scriptUrl`.

> כל עוד `scriptUrl` ריק, האתר עובד ב"מצב הדגמה" ושומר רק בדפדפן — טוב לבדיקה בלבד.
> אם משנים את Code.gs אחר כך: **פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה** (הכתובת נשארת אותה כתובת).

## 3. העלאה ל-GitHub Pages
1. דוחפים את התיקייה לריפו ב-GitHub.
2. **Settings ← Pages ← Source: Deploy from a branch ← main / root**.
3. אחרי דקה האתר זמין בכתובת `https://<user>.github.io/<repo>/`.
   - קישור לאורחים: `https://<user>.github.io/<repo>/`
   - רשימת המאשרים: `https://<user>.github.io/<repo>/guests.html`

## איך זה עובד
- אורח שולח את הטופס ← נוספת שורה בגיליון. אם אותו טלפון שולח שוב, השורה **מתעדכנת** (אין כפילויות).
- הגיליון עצמו הוא גם גיבוי — אפשר לפתוח אותו ישירות בכל רגע.
- הרשימה ב-`guests.html` נטענת רק עם הסיסמה מ-`ADMIN_KEY`.
