# O&M — אישורי הגעה לפדיון הבן

אתר פשוט על Vercel: שני דפי HTML ופונקציה אחת קטנה ששומרת את האישורים ב-Upstash Redis. בלי SQL, בלי תלויות, בלי build.

| קובץ | מה זה |
|---|---|
| `index.html` | ההזמנה + טופס אישור הגעה (את הקישור הזה שולחים לאורחים) |
| `guests.html` | רשימת כל המאשרים, סיכומים, חיפוש והורדה לאקסל (מוגן בסיסמה) |
| `config.js` | **פרטי האירוע** — שם התינוק, תאריך, מקום וכו׳ |
| `api/rsvp.js` | מקבל אישורים (POST) ומחזיר את הרשימה למנהל (GET) |

## הגדרה ב-Vercel (פעם אחת)
1. **Storage ← Create ← Upstash (Redis)** וחיבור לפרויקט. זה יוצר אוטומטית את `KV_REST_API_URL` ו-`KV_REST_API_TOKEN`.
2. **Settings ← Environment Variables**: להוסיף `ADMIN_KEY` = הסיסמה לדף המאשרים.
3. Redeploy.

## איך זה עובד
- אורח שולח את הטופס ← נשמר ב-Redis לפי מספר הטלפון. אם אותו טלפון שולח שוב, האישור **מתעדכן** (אין כפילויות).
- `guests.html` טוען את הרשימה רק עם הסיסמה מ-`ADMIN_KEY`. משם אפשר להוריד לאקסל.
- כשפותחים את הקבצים מקומית (או בכל מקום בלי ה-API) האתר עובד ב"מצב הדגמה" ושומר רק בדפדפן.
